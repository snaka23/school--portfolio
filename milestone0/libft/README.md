# Libft

*このプロジェクトは、snakagawによって、42カリキュラムの一部として作成されました。*

## 説明
libftは42のコモンコアにおける最初のプロジェクトである。標準Cライブラリの関数を再実装し、更に便利な追加関数を自作することで、C言語の基礎とメモリ操作、データ構造への理解を深めることを目的としいる。

## 作成したライブラリについて
libft.aファイルは、.cファイルをからコンパイルされた.oファイルをアーカイブした静的ライブラリである。

## コンパイルと使用手順
 指定のレポジトリからクローンし、提出されたファイルを確認する。makeコマンドを使用し、ライブラリ(libft.a)をコンパイルする。libft.aを使用する際は、自分のソースコード（main.c）でヘッダーファイルをインクルードしコンパイル時にライブラリをリンクする。

## 参考文献
各関数の挙動確認のため、man コマンドを参照した。

## AIの使用
すべてのタスクでのエラーチェック、メイン関数作成の補助として使用した。
