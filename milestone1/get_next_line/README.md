# Get Next Line

## 説明
この関数は引数として渡されたfdから読み込んだ一行を返す関数である。この関数をメインの方で繰り返し呼び出すことで、fdが指すテキストファイルを一行ずつ読み込むことができる。返される行には、末尾に改行文字を含む必要があるが、ファイルの末尾に達し、ファイルが改行文字で終わっていない場合は除く。

## 手順
指定のレポジトリからクローンし、提出されたファイルを確認する。メイン関数を作成し、ファイルを用意し、`cc -Wall -Wextra -Werror` このフラグでコンパイルを行い、`-D BUFFER_SIZE=42` のフラグも使用し、42の部分を任意の数でコンパイルする。

## アルゴリズム
静的変数を使い、読み込んだ行の次の行の始まりの地点を保存することによって、次の一行を取り出すということを可能にした。readをするときは、bufにもmallocをすることで、BUFFER_SIZEが大きな場合にスタックオーバーフローを防ぐ。
