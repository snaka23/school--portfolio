# printf

## 説明
このプロジェクトは、C言語の標準ライブラリ関数である、printfを再実装することである。可変長引数の扱いや、書式指定子の理解を深めることを目的としている。

## 手順
指定のレポジトリからクローンし、提出されたファイルを確認する。makeコマンドを使用し、ライブラリ(libftprintf.a)をコンパイルする。libftprintf.aを使用する際は、自分のソースコード（main.c）でヘッダーファイルをインクルードしコンパイル時にライブラリをリンクする。int ft_printf(const char \*format, ...)を使用する際は、出力したい型に合わせて、初めの引数に書式指定子を選択し、次の引数にその型に合わせて自分の出力したい文字やアドレスを入力する。ft_printf("%d", 12345)のように。

## アルゴリズムとデータ構造
文字列を一文字ずつスキャンし、％が現れたら、次の文字が指定の書式指定子かどうか調べ、書式指定子であれば、それに対応する関数を呼び出し、出力していく。そうでない場合は、文字列を出力していく。va_list, va_start, va_argを使い、不定数の引数を取り出した。

## 書式指定子
%c　単一文字の出力
%s　文字列を出力
%p　void \*のポインタ引数を16進数で出力
%d　10進数の整数を出力。
%i　10進数の整数を出力。
%u　符号なしの10進数を出力。
%x　小文字の16進数を出力。
%X	大文字の16進数を出力。
%%	%を出力。
